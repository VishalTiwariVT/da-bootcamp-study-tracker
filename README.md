DA Bootcamp Study Tracker
A study tracker that treats a learning plan like a budget: hours planned, hours spent, pace, and runway.
Project overview (PDF): [View Project Overview (PDF)](./DA-Bootcamp-Tracker.pdf)
Why I built it
I'm moving into a Data Analyst role and wanted my study plan to be measurable instead of vague. I split the core bootcamp path (Excel, Power BI, SQL, job prep, virtual internship) into 120 classes, estimated about 232 hours in total, and tracked real progress against that plan.
What it shows
Tick box for every class, grouped into 9 modules
% complete, hours done and hours left
Days left at my daily target (3 hours/day) and projected finish date
Pace: hours ahead of or behind plan
Daily study log, streak, XP and rank
Badges for module checkpoints and 25 / 50 / 75 / 100% milestones
Backup and restore of progress
After using it for 17+ days
Progress: [25]% complete, [59] of [232] hours
Pace vs plan: [ahead] by [5.0] hours
What I changed: [e.g. adjusted hour estimates after seeing real time per module]
How it works
Single-page web app (HTML, CSS, JavaScript), no backend
Progress is saved only in your own browser, nothing is sent anywhere
Hours per class are my own estimates (study + notes + practice), not official video lengths
Built with AI
Built with an AI-assisted tool. I defined the requirements, KPIs and study plan; the tool helped write the code.
